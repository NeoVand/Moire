# Moire — agent memory

Canvas-first WebGPU moiré tool. Vite + React + TypeScript + Three.js TSL. Do not edit the rewrite plan file.

## Product contract

- Full-bleed canvas. One studio chrome on the left (Moiré ring mark, view, layers, fields, projects, capture). `I` collapses it to a Moire pill. `E` exports a PNG.
- World Y is up. Flip Y only in `src/gpu/camera.ts` (pointer / zoom-to-cursor).
- Drag moves the selected layer (screen-space; invert layer rotation onto position). Option-drag rotates around the world origin (degrees in UI). Space or middle-drag pans. Wheel zooms to cursor. Shift on sliders is fine control.
- `rotation` is degrees. `rotationOffset` is radians, always present on the layer.
- No `maxRings`, JSON import/export theater, or fake blend modes.
- Tilings (`src/gpu/tilings.ts`) are the lattice family generalized: a tiling is a translation cell plus the polygons packed in it, and the ink is the union of those polygon boundaries — most famous tilings are "pack one shape and the gaps become the others" (hexagons touching at corners leave triangles = kagome; octagons on a square lattice leave squares = 4.8.8). Lengths are in EDGE units and `spacing` is the edge length in world units, so swapping tilings keeps the scale of the drawing. Edges are the unit-distance pairs of the VERTEX set, not the boundaries of the packed polygons: in the snub tilings two triangles meet along an edge that bounds no packed face (nine of the fifteen per cell in 3.3.3.3.6, and the whole triangle row in 3.3.3.4.4), and a face-based edge set omits them while still looking entirely plausible. The catalogue expands once into a BINNED table (`tilingTable`): the cell is divided into `bins × bins` in generator coordinates, and each bin carries the segments and vertices within `BIN_REACH` (0.62 edge units) of it, stored outright so the shader reads them with no indirection. A point folds into the cell, picks its bin, and walks only that — exact below the reach and saturating above it, which is all the ink asks (a stroke, a vertex disk, and a fill inset are each a fraction of an edge). Walking the whole list instead cost 146 ms/Mpx for two enveloped tilings against 40 binned, because the envelope re-walks it every one of 24 taps per layer. The loops are also gated on `drawEdges`/`vertexSize`, so an unused one costs nothing; CPU mirror (`tilingHits`) and GPU read the SAME table, so they cannot drift. The table is static and lives in `uniformArray`s, so choosing a tiling moves a start and a count in one slot — no pipeline rebuild, which is what makes a gallery clickable. `tilingInkFn` must stay a TSL `Fn`: as inlined nodes its dynamic `Loop` nested inside the tap `Loop` lost its scope and the ink froze at one tap (correct at sweep 0, shattered at any sweep). Catalogue entries are checked as tilings, not eyeballed — unit edges, zero polygon overlap, exact area accounting against the declared gaps, periodicity under both generators, ink density matching the largest face's incircle, and — the sharpest one — every vertex having exactly as many edges as its configuration has faces, which is local so no cell-counting boundary can fudge it (`tilings.test.ts`; the area test caught a snub-square cell of 1+√3 where the truth is √(2+√3), and the degree test caught the missing snub/elongated edges). A tiling's cell carries genuine 2D structure where a grid's is a product of two line families, so its envelope wants more taps than a grid's — residue falls as 1/√taps, and Quality raises it.
- `tileFill` inks a lattice's faces inward from their edges: a face fills only once its incircle clears the inset, so one slider sweeps from the largest faces alone through to solid. It costs nothing — it reuses the edge distance already computed — and it applies to the closed-form grids too (`fillReach` gives each type the deepest inset its solver can be trusted to). This is what makes the tilings worth having: with hairline edges the ink coverage is a few percent and the moiré is dominated by the CELL, which is a triangular or square lattice for nearly all of them, so every pair beats into the same fringe system. Filling makes the decoration the signal, and a kagome pair, an octagon pair, and a dodecagon pair then read as three different pictures rather than one.
- V1 patterns: parallel lines and radial lines through the origin; concentric circles, squares, triangles, n-gons; square / hex / triangle lattices (no offset; vertices + optional edges; X/Y scale); curves — wave, parabola, hyperbola, Archimedean spiral. Hex edges are hexagon sides, not 3-line families. The catalogue holds all ELEVEN uniform tilings (3 regular + 8 Archimedean). Studio groups them as Lines, Concentric, Tiling, Curves — the `grid` family keeps its id and holds the three regular lattices plus `tiling-periodic`, since the grids ARE three tilings.
- Radial lines: N undirected lines through the layer origin, equally spaced over π. No spacing, progressive, or offset — `lineCount` instead (default 8, max 360). `phase` is Start: a hole of that radius around the origin (0 draws through the center). Type code 8.
- Render on dirty store subscribe, rAF-coalesced. Do not rebuild `colorNode` when layer count changes.
- Pattern colors are the only accent. Background default is `#ffffff`.
- Hugeicons only. Lines use `Asterisk02Icon`, not `EqualSignIcon` or `LineIcon`.
- Studio chrome is dark. Zoom, background, and shortcuts live in the studio header.

## Inverse math (CPU and WGSL must stay twins)

Ring `n`: shape of radius `n * spacing + phase`, center `rotate(n * δ, n * θ)`, then `q = rotate(p - center, -n * θ)`.

- Centered (`δ = 0`, `θ = 0`): `mod` of `shapeRadius`.
- Circles + translation: conditioned quadratic, then neighbor integers.
- Squares + translation: closed-form L∞ axis candidates.
- Rotation, or translated polygons: Newton plus a sweep of `n` over `[nMin, nMax]`. Rotation fans the nearest index away from `|p|/spacing`; missing that range drops whole sides (the “broken segments / white holes” when zoomed out).
- Rotation past the fold radius ≈ `spacing/θ` makes `h(n)` non-monotonic: several BRANCHES of the family pass every point, and the members adjacent in residual have indices far from `n`. The scan therefore tracks its two runners-up (`ScanHit`, `vec4(h, n, alt2, alt3)`), the skip bar protects the third-nearest when the phase is measured, and the trio slots take the residual-adjacent branches over the index neighbours. Callers that consume the phase (envelope/ratio/contours — `needPhase` in `solveLayers`) must pass `acceptBelow = 0`: the early exit hands back a merely-close member, the true neighbours then measure NEARER, get rejected, and the gap falls back to nominal spacing — the envelope averages the wrong period and the carrier survives as sector hash (the hexrot bug; zoo case `hexrot-spiral-envelope`, crowded-ring block in inverseCpu.test.ts).
- `shapeRadius`: `length` (circles), `max(|x|,|y|)` (squares), regular-polygon radial metric (tri / n-gon).
- Three.js `wgslFn` only parses the first `fn` in a string. One helper per `wgslFn`, passed as includes.
- Parallel lines: `mod` of the projection. Radial lines: `max(r * |sin(wrapToHalf(atan2(p), π/N))|, start - r)`.
- Curves: type codes 9–12. No walking offset.
  - Wave: `φ = x − A sin(2π f y / 32 + ψ)`. `bend` is A, `frequency` is f (1 = one cycle / 32), `phase` is ψ. Ink `periodicDist(φ, spacing)`.
  - Parabola: one upward family `y = 0.01 B x² + n s + phase`. Bend 0 is horizontal parallels. Euclidean band `periodicDist(ψ, s) / |∇ψ|` (sides darken at high bend).
  - Hyperbola: rectangular `√|x² − y²| = n s + phase` for n ≥ 1 (east-west and north-south). No quadratic wrap.
  - Spiral: Archimedean. Spacing is the arm gap. Starts `M = max(1, round(B / s))`, used pitch `M s` so the cut stays closed. `periodicDist(r − (M s / 2π) θ − phase, s)`. Pitch 0 is concentric.
- Files: `src/gpu/inverseCpu.ts` and `src/gpu/inverse.wgsl.ts`. Tests: `node --experimental-strip-types src/gpu/inverseCpu.test.ts`.

## Fields

A field is a displacement of a layer's *index*: `shift` many members, wherever you stand. Every family spends it in its own currency — phase for the level-set families, a rotation for the radial fan, a translation along the first generator for lattices — so the fringes against an unmodulated twin are the level sets of the field.

- `src/fields/expr.ts` parses `f(x, y)` to stack bytecode. Guards (`EXPR_EPS`), opcodes and limits live there and are shared, so no evaluator can drift on numbering or on where a singularity is clamped.
- `src/fields/emit.ts` unrolls that bytecode into **straight-line code**: no loop, no dispatch, no stack, nothing passed in. It is backend-agnostic; `wgslBackend` ships and the JS backend in the test exists so the unrolling can be checked against the interpreter without a browser. Do not put an interpreter back in the shader — that was 50 ms a frame, and nearly as much for an *empty* program, because the call had to hand the program over first.
- `src/fields/evalExpr.ts` is the CPU twin (dual numbers, forward-mode AD), used by the editor's preview and the paper's CPU mirror.
- Chain rule: a term with an exactly-zero factor contributes nothing, even against an overflowed partial. `evalExpr.ts` does that in `term`; `emit.ts` folds the same zeros while generating code. A plain multiply gives `0 · ∞ = NaN` and poisons the gradient.
- One generated `fn moireField{slot}` per layer that carries a field, so **a new expression is a new material**. `MoireRenderer` debounces that on `FIELD_SETTLE_MS` (220 ms) and holds the last frame across the build. Amount and extent are uniforms and never rebuild.
- Tests: `node --experimental-strip-types src/fields/expr.test.ts`.
- A circle-valued field mints DEFECTS: `theta/tau` at integer amount A ends A fringes at the origin (the fork grating; zoo `line-fork-render`/`line-fork-envelope`). The signed count of fringe endings inside any loop is the enclosed charge × amount — quantized, localized, additive, blind to the field's exact part — and the fringe law fails inside the core r* = 2As/π where η crosses 1/4 (`node --experimental-strip-types paper/tools/exp/defects.mjs`, gates exact). A NON-integer amount tears the drawing along the evaluator's branch cut; that tear is real, not a bug — it carries the fractional winding.

## Renderer

- The slot UNIFORMS are a fixed `MAX_LAYERS` (12) array, allocated once and never reallocated — but the MATERIAL is compiled only for the slots a stack actually uses (`slotsNeeded` = layers present, clamped). An inactive slot is not free: its `If(active)` branch still costs registers, and the lattice coordinates every slot contributes are computed in uniform control flow because their screen derivatives cannot live inside a branch. Twelve slots for a two-layer drawing measured **3.8× the per-pixel cost** of two, and specialising took the plain two-ring scene from 19.6 to 0.3 ms/Mpx. Hiding a layer stays a uniform write (`active = 0`) and never rebuilds; changing the layer COUNT or a field expression does. Field edits wait out `FIELD_SETTLE_MS` because they are being typed; a count change rebuilds on the next frame, since a click has already stopped and a new layer must not be invisible for a quarter second.
- Envelope view is the continuous-domain mean ink: one pass with `ENVELOPE_TAPS` taps sliding each family through exactly one of its own local periods. Level-set families slide their residual with `phaseDistWgsl` on the `(r, rUp, rDown, floor)` phase sample — no re-solve per tap. Lattices resample instead: one generator advances by `u` coherently and the other by the golden ratio (a rank-1 rule — in lockstep a lattice beats against itself). Which combination rides `u`, and stepped which way, is chosen per pixel among the first three rings of the dual lattice — `(1,0) (0,1) (1,1) (1,−1) (2,1) (1,2)` plus the doubled generators `(2,0) (0,2) (2,2)` — by matching each one's exact index gradient (`local · b_k`, linear, so `dFdx` is exact) against the ranked partner's `gradA`, forward or backward, with a per-kind ink weight multiplying the match error (a honeycomb's wall families are its SECOND dual ring — normals `(1,−1) (2,1) (1,2)`, pitch `(√3/2)s` — so hex weights favor ring two; ring three is the honeycomb's vertex rows and a thin grid's second harmonics; square has no ink at `(2,1)` or `(2,2)`; each schedule is the unimodular completion sending its own combination to `su` and every other candidate to a nonzero mix, so the lattice still never self-hatches — except the doubled combinations, whose bare generator rides `u/2` and half-washes, a carrier-scale residue accepted under the coarse fringe). A global choice erases beats along the unchosen directions or counted the other way (the lattice edition of the sum-moiré convention; a ring partner's counting direction rotates around its centre). The envelope's ranked pair falls back to the topmost eligible layer alone (`envelopePair`) — the ratio view still needs two, but with one grid and one family the partner gradient would otherwise be the zero vector and the choice degrades to noise. Lattice⊗lattice: with no scalar layer visible, `latA` names the topmost lattice as reference (twist mode); every other lattice matches each generator, signed, to the reference's per pixel and rides the SAME `(u, {iγ})` schedule, so both slow characters of a twist pair (a₁−b₁, a₂−b₂) survive the average exactly while carriers, self-beats, and cross-beats scramble away (w = (1, γ, 1, γ) on T⁴). A sole lattice with no partner washes to its own cell mean. With a scalar visible the legacy partner-gradient path runs and lattice⊗lattice beats remain unhandled there. A rate DEVIATION is never a hard per-pixel switch: the sweep runs the deviated and the diagonal chains together (they differ only in the ranked scalars' slide rates) and blends by `devW` — zero where the winner ties the best zero-sum candidate, and fading out again once the winner's own eta passes ~1.7–3.4× the threshold, because a sum/second-order beat can keep winning while its fringes shrink to carrier-fine hash, and holding its schedule paints a hash annulus ending in a hard rim (two equal-pitch ring families drew that rim around their midpoint; zoo `rings-sum-handover`, `walk-pair-envelope`). Residual centre hash where a ZERO-SUM winner is out of regime is the mask slider's job, not the schedule's. Contrast expands about `nominalCoverage`, whose ink model must be roughly right in both directions: count a lattice's families or the pivot drives the frame black, and honour each kind's true row pitch and duty (`familyInk`: square 2 families at s full duty; triangle 3 at (√3/2)s full duty; honeycomb 3 at (√3/2)s but only THIRD duty — 3 edges of length s per cell of area √3·1.5·s²) or the pivot sits far darker than the true mean and the envelope of a hex twist blows out to blank paper.
- Ratio view is the heterodyne ratio over the characters of the JOINT index torus: the THREE topmost visible scalar-index layers (radial fan counts) picked into `ratioA`/`ratioB`/`ratioC`, PLUS the topmost two lattices' dual-ring ink families picked into `scanLatA`/`scanLatB` (measurement-only uniforms, independent of the sweep's `latA`/`latB`) — never a rebuild. Lattice characters fold into `etaAll` (heat map, regime mask) but not the scalar-only `eta` that gates the scalar contour channel and the rate deviations: each combination against the ranked scalar both ways, and matched same-combination differences across the lattice pair, all pen-gated by the shared `DUAL_RING` ink table (no-ink combinations must not darken the map). The view engages with two scalars, a scalar plus a lattice, or a lattice pair (`canMeasure` in writeSlots); with a lone scalar `ratioB` stays −1 — a self-pair's beat is identically zero and floods the map with a false eta of 0, which is also why the A-B pair carries the same validity gate the C pairs do (zoo cases `grid-ring-ratio`, `grid-twist-ratio`). Fractional index is the phase sample's signed residual over the gap toward `min(rUp, rDown)` (smaller residual is always the next member up); its gradient is ANALYTIC wherever the family has a closed form — the `*IndexDir` twins beside their phase functions in `inverse.wgsl.ts` give the unit phase-gradient direction, the sample's measured gap gives the magnitude, and TSL's `dFdy` runs along WebGL's bottom-up window y so world y needs NO flip (a flip mirrors the scalar gradients against the lattices' dFdx-based ones and the candidate matching dies — grid-tri-line-contours went 54% wrong that way) — with `dFdx/dFdy` (integer wraps rounded out of the per-pixel deltas) kept only for walking families, whose direction is the argmin's facet normal that only the scan knows. A visible moiré is an integer character `k·ξ`, and the candidate set is NOT an order cap: on every ranked pair the scan runs per-pixel Lagrange-Gauss reduction of the gradient lattice `{a·gP + b·gQ}` (8 unrolled steps, quotient clamped, integer coordinates carried in floats — once a remainder fails to shrink the unroll idles, so no done flag) and scans the reduced short vector s plus the window `{i·s + j·t, |i| ≤ 3, j ∈ {1,2}}` under the AMPLITUDE weight |a·b| (a beat rides one layer's |a|-th and the other's |b|-th harmonic, decaying like 1/m each; unweighted, good rational approximations exist at every order and the min favours beats no ink carries). A |k| ≤ 2 cap missed 858 of 4000 visible fringes clustering at pitch ratio ≈ 3 (`paper/tools/exp/convergents.mjs` — the shipped scheme misses 1, names the brute-force winner 99.8%; the second window row matters because the weighted winner need not be a shortest vector: a longer lattice vector can carry smaller coordinates); two line families at 3:1 beat in `(3,−1)`, which the cap could not form — the envelope held a phantom `(2,−1)` schedule, washed the standing fringe, and the map read blank (zoo `pitch-3to1-*`, `pitch-5to2-envelope`, `rings-3to1-ratio` — the last has spatially varying ratio, guarding the per-pixel-ness). The old six characters stay as a compile-time floor, and the REDUCTION IS LICENSED BY `hasGrad`: dFdx gradients are per-quad noise the reduction reads as slow high-order characters (walk-pair-envelope stippled in patches), so a walking pair keeps the floor at the OLD semantics — raw η to the map, 1.5 order-2 pick penalty — via `mix(old, |a·b|, okP·okQ)`, while analytic pairs pay one coherent weighted merit everywhere. PLUS the zero-sum ternaries `(1,1,−2)` and permutations (weight 2 analytic, old 1.5 walking) — beats between beats, slow where e.g. `∇ξA+∇ξB ≈ 2∇ξC` (three ring families arrange it at the harmonic-mean spacing; the third layer's SECOND harmonic carries it, so duty 1/2 nulls it). Dark ≤ threshold (default 1/4) is the fringe regime; `ratio` widens the solver guard like `sweep`. Fewer than two eligible layers renders the plain composite. On analytic pairs whose local ratio varies, the rational stations become PLACES — `radial-pair-contours` resolves discrete commensurate pockets along the axis between two fans, a Stern-Brocot ladder in pixels.
- The envelope reuses that η twice: `envMask` fades the view to its pivot past the threshold (band follows the `ratioThreshold` uniform), and the ranked layers advance at the winning character's rates instead of the plain diagonal. On K layers the diagonal (all rates 1) preserves the whole ZERO-SUM sublattice — every pairwise difference and every zero-sum ternary at once — so unranked layers always ride it, zero-sum winners deviate nothing, and only a non-zero-sum winner (`(1,1)` sum, `(2,−1)`, `(3,−1)`, `(5,−2)`… — any order the reduction certifies) puts its own pair on `(|kQ|, ∓kP)` while the third ranked layer stays at 1; the sweep's `slide` wraps any integer rate, and a rate-5 schedule at 24 taps samples each period ~5 times, which is why `pitch-5to2-envelope` raises the tap dial. Scanning only the top pair chose that deviation blind — a sum beat between the top two scrambled the slower ring⊗ring difference the second layer made with the THIRD (fringe stood in the render, washed from the view; adding a fourth layer "fixed" it by shoving the rings off the ranked pair). Pair uniforms stay warm during any enveloped frame. The Contours toggle (envelope panel, `envelopeContours` + `contourWidth`/`contourBands`) overlays the winning character's integer level sets in accent — envelope OR raw render (it widens the solver guard like `ratio` so xi is measured between strokes) — as a constant-screen-width stroke (residual over the winner's recorded beat rate) plus an optional soft band in INDEX units that spans the true fringe width, swelling where the character runs flat; both fade past the ratio threshold and gate on a nonzero beat rate (A==B fallback would otherwise paint the frame). Lattices index members by an integer PAIR, so their fringes are invisible to the scalar scan; the overlay reads them off the sweep's own generator matching instead (`latB` uniform: the twist partner, else the topmost lattice). In twist mode the matched pair's characters D1, D2 are recorded with BOTH sides' gradient vectors and combined into the latB kind's FUNDAMENTAL dual-ring families — (1,0)/(0,1) for square, (1,−1)/(2,1)/(1,2) for the honeycomb's walls, (1,0)/(0,1)/(1,1) for triangle — every combination survives the lockstep sweep, and the `on` gate (kind ink weight ≤ 1.05) admits only families the ink carries, so a hex twist contours its visible wall-beat rosette skeleton, not two faint generator lines. Against a scalar partner the overlay draws the best beat-capable combination minus the ranked scalar. Each channel has its own rate/eta/on gate (`grade` takes a channels array), and a lattice field counts as generator-1 index (the tap resample advances by `uLat + shift`), so a field-warped grid against its twin contours the field's level sets.
- Stroke: `halfT = max(thickness/2, 1.15 * pixel)` so hairlines and small geometric gaps do not pepper at zoom-out. `pixel = 1/zoom`.
- `devicePixelRatio` clamped to 2. Camera at `z = 1`, `near = 0.1`. `toneMapped = false`.
- First paint waits on `compileAsync`. `MoireStage` shows the ring mark with “Compiling” until the first frame. The first load then eases two default concentric layers into the preset.

## Scene zoo (golden-image regression)

`npm run zoo` renders every case in `tests/zoo/scenes.mjs` through the real pipeline — Vite dev server, headless Chrome, WebGPU on the actual GPU — and pixel-compares against `tests/zoo/golden/`. `npm run zoo:update` re-blesses after an intended visual change; `npm run zoo -- grid` filters by name substring. Run the zoo before and after ANY change to `composite.ts`, `renderer.ts`, or the solvers; bless only diffs you can explain.

- Cases live in `tests/zoo/scenes.mjs`: complete scene JSONs (layers written out in full so app-default drift can't move a golden), one per cell of the feature × layer-class matrix. Each carries `coords`, the per-layer index-coordinate count (1 scalar, 2 lattice, 5 for a future Penrose layer) — the schema is already shaped for tilings. A failing case's JSON loads straight into the app via the export panel's drag-drop.
- The app side is `src/zoo/bridge.ts` (`window.__zoo`), loaded only in dev behind `?zoo`. A capture is a pure function of the scene file and the pixel size: the bridge pins the camera zoom so the stage's own layout cancels out of `snapshot`'s framing math (a scene at zoom 1 shows 640 world units across the capture), and `MoireRenderer.settle()` flushes the field-expression debounce so captures never race a material rebuild.
- Goldens are per-backend: `golden/manifest.json` records which backend blessed them and the runner refuses to compare across backends. Current goldens: webgpu (Apple Metal). `tests/zoo/out/` (renders + diffs) is gitignored.
- Failure budget is `MAX_DIFF_RATIO` (0.05% of pixels at pixelmatch threshold 0.12) — far below any real regression (a one-constant contour tweak moves 1–10% of pixels) but above driver-level noise.

## UI

- One `Studio` panel with the Moiré ring mark (`ui/MoireMark`: two concentric-circle families a hair apart — also the favicon and the paper site wordmark). Do not resurrect a separate top HUD, right inspector, or bottom filmstrip.
- Projects live behind the folder icon: `ProjectsDialog` over `src/store/library.ts` and `src/store/db.ts` (IndexedDB, stores `projects` and `session`; a project's scene is the export JSON string). Autosave is a **throttle**, not a debounce — an idle preview writes the store every frame, and a pure debounce under a continuous change stream never fires at all. The opening animation is a seeded library project (`seedOpening`), not a special case in the renderer. `window.__moire` exposes `{project, library, db, params, motion, recorder, video, transport}` in dev, because a dynamic `import()` from the console gets a different module instance than the app and its store is a phantom.
- Capture lives behind the camera icon: `CaptureDialog` — stills (aspect chips, 1/2/4×), PNG frame sequences straight to a directory handle, and MP4/WebM. Stills scale by a multiple of the window; recordings state a *height* instead (`VIDEO_SIZES`, HD…4K), because the multiplier that gives a fine still gives a frame no encoder will take. Format availability comes from a real six-frame encode (`probe` in `src/gpu/video.ts`), never from `VideoEncoder.isConfigSupported`, which returns **true** for H.264 at 4K/120 and then fails mid-take with Chromium's `"Flushing error"`. Do not show a predicted file size: the bit rate of a moiré take is nowhere near any constant worth quoting. `showDirectoryPicker({mode:'readwrite'})` — a mode-less picker hands back a read-only handle and the failure surfaces much later; do not follow it with `requestPermission`, which needs transient activation that awaiting the picker has already spent.
- Motion is one clock and pure functions of it (`src/types/motion.ts`, `src/store/transport.ts`). Never `v += rate * dt`: an accumulator cannot be scrubbed, drifts against its neighbours, and never records the same take twice. `period` always means one traversal, so a bounce's cycle is `period * 2` and switching modes does not silently halve the speed. Every slider carries a play button that opens `MotionPanel` (live curve, playhead moved through a ref rather than React); `MotionList` in the capture panel is the only way to reach a motion whose layer is not selected, and its mute/solo are session state, never document state. A recording does not watch the transport — `recordFrames` sets `t = t0 + n/fps`, renders synchronously and waits for the pixels — which is why there is no "record on play" and why the paper can claim a take is reproducible (§7.5).
- Parameters are addressed by path (`src/store/params.ts`: `view.<key>`, `layer.<id>.<key>`, `layer.<id>.offset.x`, `camera.zoom`), which is what lets motion, capture and the scene file talk about a knob without importing the component that draws it.
- Frosted HUD: `--hud-bg` + `backdrop-filter`. Selected layer is a quiet ring, not an inverted overlay.
- Every slider has a reset affordance next to its label when dirty. Defaults live in `LAYER_DEFAULTS`.
- Envelope is a header icon that ONLY toggles the view. All research settings live in the Research panel (microscope icon beside it, `ResearchControl`, `FloatingPanel` id `research`): an Envelope toggle row plus its dials (contrast, sweep, exposure/lift, taps, mask — all view uniforms, never a rebuild), the Contours block (toggle, width, bands), and the fringe ratio (toggle + Overlay `ratioBlend` + Threshold `ratioThreshold`; `R` still works). Envelope and ratio retire each other in `setView`; the envelope sliders dim while the view is off. The Shortcuts entry moved out of the header into the About modal beside the Repository link (`moire-shortcuts` event). Fields are a calligraphic `f` on each layer row that opens the `FieldEditor`, also a `FloatingPanel` (presets, syntax-highlighted expression via `src/fields/highlight.ts` — a pre under a transparent textarea, classes from the parser's own name tables — live CPU preview with fringes/field modes and a heavier zero set, amount, extent, reference, and an enable switch that mutes by zeroing the amount uniform so A/B is instant; `f` shows muted-filled when a source is present but off). `FloatingPanel` (src/components/ui): no backdrop, drags by header with pointer capture, remembers position per id in localStorage, raises on pointer-down, Escape peels only the topmost. Active buttons are marked by fill and colour, never a ring. No `View` section, no field controls inline in the layer panel. Help lives at the control, not in paragraphs: every `IconButton` names itself on hover through the portal bubble in `ui/useHoverTip.tsx`, and every tunable parameter carries an `InfoTip` (`ui/Tip.tsx`, the circled i; `Slider` takes `info`) with one sentence on what the knob does — no caption blocks under panels.
- Tilings are picked by picture, not by name: the Tiling family's variant row is one wide chip showing the current tiling, opening `TilingGallery` — a thumbnail popover grouped Regular / Semi-regular / Other. The thumbnails are the catalogue's own segments drawn to SVG (`tilingPatch`), never artwork, so a thumbnail cannot show a tiling the layer would not draw and a new catalogue entry brings its own picture. The three regular tilings carry `builtin` and resolve to the existing `grid-*` types (keeping their closed-form fast paths); everything else is `tiling-periodic` plus the catalogue name, and the name rides along either way so switching to a regular tiling and back remembers the entry. `currentTiling`/`tilingChoice` live in `src/lib/tilingChoice.ts`, not the component, so fast refresh keeps working.
- Switching a layer to lines, grid, or curves zeros `offset` and `rotationOffset`. Type changes ease on the GPU (~280 ms): one stroke, mixed distances. The store snaps to the target.

## Paper site

`node paper/tools/html/build-html.mjs` converts the paper's LaTeX wholesale into `public/paper/index.html` — a single light-theme page (warm paper ground, Newsreader + Inconsolata, KaTeX via CDN with `output: 'html'`) served by the app; the About modal's "The paper" link opens it. Never hand-edit `public/paper/` — fix the converter or the LaTeX and rebuild. The converter flattens `\input` recursively, escapes `<`/`>` before injecting HTML (a raw `$m<s$` once swallowed half a proof as a `<s>` tag), numbers floats in document order, renders equation numbers outside a scrollable `.eq-scroll` box, and compiles each tikzpicture standalone through tectonic + pdftoppm, cached by content hash in `paper/.build/tikz-html/` (gitignored) with `data/*.csv` paths made absolute, carrying along any argument-free `\newcommand` the float defined above its picture (`localDefs`) — a figure that sets its own `\stripw` otherwise fails as an undefined control sequence in a file nobody wrote. Copied figures dedupe against `paper/figures` blobs, so committing `public/paper/` is cheap. After editing the paper, rebuild and commit the regenerated page.

`node paper/tools/arxiv.mjs` builds the public, named pair: it rewrites `paper.tex` and `supplemental.tex` into `paper/arxiv.tex` and `paper/arxiv-supplemental.tex` (gitignored) with `anonymous, review` dropped, `nonacm` added, the submission ID gone, a placeholder ORCID removed, and the supplemental's `\externaldocument` pointed at the named build — then compiles both. Generated rather than kept as a second copy, because a stale public PDF looks exactly like a current one. Every substitution asserts, so a `paper.tex` that has moved underneath the script stops it.

## Checks

**`npx tsc --noEmit` checks nothing here.** The root `tsconfig.json` is a solution file — `files: []` and two references — so that command typechecks an empty program and exits 0 no matter what is broken. `npx vite build` is no better: esbuild strips types without reading them. Use what CI uses:

```
npm run build      # tsc -b && vite build -- the actual typecheck
npx eslint src
npm run zoo        # before AND after any change under src/gpu/
```

CI is `.github/workflows/` → Deploy Pages, and it runs `npm run build`. A green `tsc --noEmit` next to a red pipeline means this trap, not a flake.
